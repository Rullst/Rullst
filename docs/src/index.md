### Why Rullst?
- 🚀 **Extreme Speed:** Built in Rust, powered by `tokio` and `axum`.
- 🧩 **Wasm Islands & Hybrid SSR:** Zero-Bundle HTMX default with optional Leptos/Dioxus SSR adapters.
- 📖 **Interactive Scalar Docs (`/docs`):** Built-in OpenAPI UI via `cargo rullst make:scalar`.
- ☸️ **Kubernetes Native:** Cloud-Native manifest scaffolding (`cargo rullst make:k8s`) with `/health` & `/ready` probes.
- 📡 **Rullst Radar & Prometheus:** Kernel-level telemetry visualizer with native `/metrics` exporter.
- 🛡️ **Air-Gapped Local AI Security:** Run local LLMs via Ollama (`llama3`, `mistral`) for self-healing error consoles & SOC threat radar.
- 📦 **Batteries Included:** ORM (rullst-orm), Auth, Revenue Dashboard, Jobs, Mail, Scheduler, Cache, Security.
