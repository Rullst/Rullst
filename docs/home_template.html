💡 The Rullst Philosophy

Unlike other frameworks, Rullst strives to be simultaneously simple and complete, with a relentless focus on security, AI-native architecture, and developer experience (DX).

The origins of this philosophy can be traced back to the creation of Rust by Graydon Hoare, who sought memory safety to eliminate runtime elevator crashes. Rullst carries this exact mindset into web development: eliminating runtime panics, hidden reflection magic, and framework guesswork.

Our Core Tenets

  • Simple yet Complete: Batteries included out-of-the-box: Parameterized ORM, JWT & Session Auth, RASP Security Shield, Local/Cloud AI Client, SaaS Billing, and Real-Time Telemetry.
  • AI-Native & Token Efficient: Strongly typed static dispatch (`impl Trait`) and macro delimiters (`routes!`, `html!`) save up to 70% in LLM prompt token context when building with Cursor, Claude, or Copilot.
  • Zero-Panic Production Guarantee: All runtime paths use typed `AppError` enums. No unexpected panics in production.

How to build a SaaS with Rullst

Active Record & Parameterized SQLx ORM

Declare models with type-safe macros, transparent field encryption, and zero SQL injection vulnerability.

use rullst_orm::Orm;
use rullst::db::FromRow;

#[derive(Debug, Clone, FromRow, Orm)]
#[orm(table = "users")]
pub struct User {
    pub id: i32,
    pub email: String,
    #[orm(encrypted)] // Transparent Vault field encryption
    pub ssn: String,
}

// Simple Active Record queries
let user = User::find(1).await?;
let all_users = User::all().await?;

RASP Protection & Granular RBAC

Pre-controller threat shield, Passkeys/WebAuthn, and ownership-based BOLA protection.

use rullst_security::{RbacGuard, HtmlSanitizer};
use rullst_core::AppError;

pub async fn update_document(user: User, doc_owner_id: i32) -> Result<(), AppError> {
    // Ensures current user owns resource or has 'admin' role
    RbacGuard::authorize_owner_or_role(&user, doc_owner_id, "admin")
        .map_err(|e| AppError::Forbidden(e))?;

    let safe_content = HtmlSanitizer::sanitize("User Content");
    Ok(())
}

Provider-Agnostic AI Client (`rullst-ai`)

Connect to ANY local runner (Ollama, LM Studio, vLLM, LocalAI) or commercial cloud (Gemini, Claude, OpenAI, DeepSeek) with prompt injection filters and PII masking.

use rullst_ai::ai::{AiClient, AiGuardrails, Message};

let client = AiClient::auto()?; // Detects Ollama / LM Studio / Gemini / OpenAI credentials
let clean_prompt = AiGuardrails::sanitize_prompt(&user_prompt);

let response = client.prompt(&clean_prompt).await?;

Why Rullst? Key Architectural Benefits

🛡️ Enterprise-Grade Security Shield

Rullst is "Secure by Design", shipping natively with pre-controller RASP AST inspection, Passkeys/WebAuthn FIDO2 authentication, Double-Submit CSRF, and synthetic bot honeypots.

🔐 Enterprise Vault & Zeroization

Field-level transparent encryption (#[orm(encrypted)]) paired with cryptographic memory wiping (Zeroize) ensuring zero memory leak vulnerabilities.

⚡ Auto-Migrations in Dev Server

Experience unmatched Developer Experience. cargo rullst dev automatically and silently runs pending migrations before hot-reloading your application.

🤖 Provider-Agnostic AI Integration

Connect seamlessly to ANY local LLM (Ollama, LM Studio, vLLM, LocalAI) or commercial cloud (Gemini, Claude, OpenAI) with prompt injection filters and PII masking.

🛡️ Zero-Panic Production Policy

All runtime paths use strongly typed AppError enums. Zero runtime panics or hidden unwraps in production code.

🔒 Strict Type Safety (No Dynamic Traits)

Rullst avoids heavy usage of dyn Trait in favor of static dispatch. This guarantees maximum compiler optimizations, monomorphization, and smaller binaries.

🗺️ Explicit API Design

No hidden magic or unexpected middleware sequencing. Routes, state, and filters are explicitly declared for maximum maintainability.

🌍 Edge Fusion & Replication

Compile to WebAssembly for Cloudflare Workers globally, backed by built-in Turso/libsql replication for sub-millisecond database read latencies worldwide.

📱 Omni-Frontend Wasm & Tauri

Write interactive client components strictly in Rust (#[client_component]) and package desktop/mobile apps natively with Tauri.

📈 Performance CI Dashboards

Track automated microsecond regression benchmarks updated on every commit across all crates.

🔒 Privacy Policy & Data Protections

1. Privacy by Architecture: The Rullst Framework is architected for zero data tracking. Open-source local installations never transmit your codebase, database records, or credentials to third-party telemetry servers.

2. Local & Air-Gapped AI: When utilizing rullst-ai with local runners (Ollama, LM Studio, vLLM, LocalAI), prompts and vector embeddings remain 100% on your local machine with zero external network leakage.

3. Transparent Vault & Memory Safety: Sensitive fields decorated with #[orm(encrypted)] are encrypted with AES-256-GCM and purged from RAM upon drop via Zeroize.

4. Cookies & Session Storage: Web cookies used by the framework are configured with HttpOnly, SameSite=Lax, and cryptographic HMAC session binding.
