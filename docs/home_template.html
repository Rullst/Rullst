Provider conformance kits ↗

Recipes, not integrations. MongoDB, DuckDB and Qdrant are application recipes: your code uses their official crates directly. Their built-in adapters were removed in 13.0.0-alpha.5. v13 is in prerelease: 13.0.0-alpha.6 is the 13.0 feature freeze, followed by 13.0.0-rc.1 (fixes and documentation, and the changes the maintainer approved one by one after the freeze, two of them breaking) and 13.0.0. Cargo never selects a prerelease on its own, so name the exact version from crates.io (=13.0.0-alpha.6) and use its matching immutable tag rather than the moving main branch. The v12 line reached end of life on 16 October 2026 with 12.3.0, and the v12 branch is frozen; move applications with the v12 → v13 adoption guide. The legacy v5 branch is no longer maintained either. Scope and limits lists what Rullst does not do by design and what its own tests cannot establish. Prerelease and stable describe the framework API lifecycle, not automatic approval of an application's authorization, provider configuration, operations or deployment.
