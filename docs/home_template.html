One workflow. Reviewable output.

01

Choose a starting point

Pick a bounded blueprint, persistence profile and frontend mode instead of assembling an undocumented stack by hand.

02

Own the generated Rust

Review routes, models, migrations and middleware in your project. Rullst does not hide application behavior behind runtime reflection.

03

Verify the exact boundary

Run ordinary Cargo checks plus Rullst's documented database, security, portability and release evidence for the features you enable.
