# Security Policy

This crate follows the
[Rullst security policy](https://github.com/Rullst/Rullst/blob/main/SECURITY.md),
which lists the supported versions and how fixes ship.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.
Report them privately, by email to `officialrullst@gmail.com` or through
GitHub's [private vulnerability reporting](https://github.com/Rullst/Rullst/security/advisories/new),
as the Rullst security policy describes.
