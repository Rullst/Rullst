### Changed
- The `V13-AUTH-SESSION-EPOCH-CALLS` upgrade finding now says that a `decrypt_session_claims` call reached only for cookies that are not registry cookies, the transition the migration guide recommends, fails nothing at run time and is removed once the epoch cookies have expired (30 days by default). The alpha.6 to rc.1 checklist and the upgrade section of the migration guide now tell the reader to search the repository for the previous version string and list the usual places (CI files that install `cargo-rullst`, README badges, deployment documentation, and kits or generated projects that embed a Rullst manifest and lockfile). The `StudioBuildError::LocalAccessRequiresDebugBuild` and `NexusBuildError::LocalAccessRequiresDebugBuild` messages now name both conditions, a debug build and a development or test environment, instead of blaming the build when the environment is the cause.
